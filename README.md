🔐 Login Authentication System

A React authentication system built to practice Context API, React Hooks, and authentication state management.

🚀 Features
User login system
Authentication state management using Context API
Limited login attempts
Account lock after multiple failed login attempts
30-second countdown timer during account lock
Automatic unlocking after the countdown ends
Dynamic UI based on authentication state
Custom CSS design for the countdown timer
🛠️ Technologies Used
React.js
JavaScript
React Context API
useState
useEffect
setInterval
CSS
Git & GitHub
📚 Concepts Practiced

This project helped me practice:

Creating and using an AuthContext
Sharing authentication data between components
Managing state with useState
Running side effects with useEffect
Working with setInterval
Cleaning up intervals with clearInterval
Handling failed login attempts
Implementing an account lock mechanism
Creating a countdown timer
Conditional rendering in React
🎯 Project Purpose

This project was created as a practical React exercise to strengthen my understanding of Context API, state management, useEffect, and working with timers.
